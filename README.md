# Student Registration System

A web-based Student Registration System built using Java Servlets, JDBC, and MySQL.

## Technologies Used
- Java
- Java Servlets
- JDBC
- MySQL
- HTML and CSS
- Apache Tomcat
- Eclipse IDE

## Features
- Student registration through a web form
- Processing form data using Java Servlets
- Database connectivity using JDBC
- Storing student details in MySQL

## Project Structure
- `src/` — Java source code
- `WebContent/` — Web application files, if applicable
- `WEB-INF/` — Web deployment configuration, if applicable
- `database.sql` — Database setup script

## Setup Instructions
1. Download or clone this repository.
2. Create the database and table using `database.sql`.
3. Configure your local MySQL connection settings.
4. Import the project into Eclipse as a Dynamic Web Project.
5. Configure Apache Tomcat and the MySQL JDBC driver.
6. Run the application on Tomcat.

## Learning Outcomes
This project demonstrates practical experience with Java Servlets, JDBC, SQL, and web application development.
